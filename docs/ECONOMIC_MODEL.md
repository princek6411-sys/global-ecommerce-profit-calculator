# ProfitPilot Economic Model

## One economic language

All supported source systems translate into a shared economic model. Platform-specific code performs acquisition and mapping; the calculation engine remains the single economic authority.

## Data boundary

RAW → NORMALIZED → ECONOMIC

Raw source records are evidence. Normalized records are standardized interpretation. Economic records are calculations.

## Profit boundary

Profit is never inferred from a payout alone. The current product uses an explicit calculation basis. Seller Intelligence labels settlement-derived profit as estimated where the source does not provide complete P&L evidence.

## Cash vs profit

Revenue ≠ cash
Settlement ≠ profit
Payout ≠ profit
Profit ≠ bank balance

## Trust

Important values should carry source/trust, freshness and confidence where technically available.
