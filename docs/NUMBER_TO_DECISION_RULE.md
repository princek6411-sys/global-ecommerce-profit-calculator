# Global UX Principle — Number to Decision

Every important number must help the visitor reach a decision:

**NUMBER → MEANING → REASON → NEXT ACTION**

Do not show an important financial result without enough context for the visitor to understand what it means.

Do not invent meaning, reason, or action. When evidence is insufficient, say so explicitly.

Dense tables do not require four lines in every cell. Clear labels, surrounding context and progressive disclosure are enough.
